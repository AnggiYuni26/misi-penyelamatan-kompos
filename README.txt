MINI-GAME MISI PENYELAMATAN KOMPOS — REVISI FINAL

ISI PAKET
- index.html: aplikasi mini-game
- 7 file PNG: desain visual final (941 x 1672 px)
- Lampiran_Bank_Skoring_Final_Misi_1-4(1).txt: acuan skoring lengkap

MENJALANKAN SECARA LOKAL / OFFLINE
1. Ekstrak ZIP ke satu folder.
2. Jangan memisahkan index.html dari tujuh file PNG.
3. Buka index.html menggunakan Chrome, Edge, Firefox, atau browser modern.
4. Permainan berjalan secara lokal tanpa internet. Kemajuan disimpan pada localStorage browser/perangkat yang digunakan.
5. Versi daring dapat dibagikan melalui tautan setelah folder diunggah ke layanan hosting statis.

ALUR DAN FITUR
- COVER → BRIEFING → M1 → M2 → M3 → M4 → CASE CLOSED.
- Identitas nama dan kelas.
- Pemilihan tepat dua kondisi pada Misi 1.
- Pemilihan satu strategi S1–S4 pada Misi 3.
- Kolom jawaban Misi 1–4.
- Timer 5 menit per misi.
- Jawaban terkunci setelah dikirim atau waktu habis.
- Skor hanya ditampilkan pada CASE CLOSED.
- Rekap skor M1–M4 dan skor akhir maksimum 100.
- Tidak ada tombol kembali, reset, atau mengulang permainan.

CATATAN PENILAIAN
Lampiran bank skoring final tetap disertakan sebagai acuan. Mesin skor yang berjalan di browser ini masih menggunakan indikator/heuristik kata dan frasa; mesin ini tidak memahami seluruh konteks bahasa alami seperti penilai manusia. Karena itu, skor otomatis perlu diuji dan dikalibrasi menggunakan contoh jawaban murid serta diverifikasi sebelum dipakai sebagai data penelitian. Jangan menganggap heuristik ini sebagai implementasi semantik penuh dari seluruh pola bank.

CATATAN PENGUJIAN
Paket ini telah diperiksa struktur file, pemuatan HTML/JavaScript, dan susunan aset. Uji interaksi akhir pada perangkat HP dan browser yang akan digunakan di kelas tetap perlu dilakukan sebelum dibagikan kepada murid.
